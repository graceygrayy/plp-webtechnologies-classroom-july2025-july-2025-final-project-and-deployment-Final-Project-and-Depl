
# Gracey Oil Perfume Multipage Website

## Project Purpose
This project is a multipage website for Gracey Oil Perfume, designed to showcase and sell a range of luxurious oil perfumes. The site aims to provide an elegant, user-friendly, and responsive experience for visitors, allowing them to learn about the brand, browse products, and get in touch easily.

## Project Structure
- **index.html**: Home page with hero slider, featured products, and navigation.
- **products.html**: Displays all available oil perfumes with images, names, and prices.
- **about.html**: Information about the brand, mission, and FAQ section.
- **contact.html**: Contact form and business contact details.
- **styles.css**: All site styling, including responsive layout and animations.
- **script.js**: JavaScript for interactivity (slider, FAQ, mobile menu, form feedback).
- **images/**: Folder containing all product and branding images.

The site uses a consistent header, footer, and navigation across all pages. It is fully responsive and includes interactive elements such as a background slider, FAQ accordion, and contact form feedback.
